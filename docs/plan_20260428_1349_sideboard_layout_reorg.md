# SideBoard Layout Reorganization & Advanced Design Proposal (v3.0)

## 1. Problem Summary (문제 요약)
현재의 `SideBoard`는 정보 입력과 목록 조회가 하나의 수직 흐름에 섞여 있어, 데이터가 많아질수록 입력 폼과 목록 간의 시선 분산이 발생합니다. 또한, 현재 선택된 날짜에 대한 정보가 상단에 국한되어 있어 전체적인 레이아웃의 입체감이 부족합니다.

## 2. Design Goal (디자인 목표)
- **공간의 재정의**: 입력과 조회의 영역을 시각적으로 명확히 분리하여 사용자의 인지 부하를 감소.
- **상시 오버레이(Always-on Overlay)**: 사이드바를 단순히 밀어내는 패널이 아닌, 캘린더 위에 부드럽게 떠 있는(Floating) 프리미엄 레이어로 전환.
- **정보 계층 고도화**: 핵심 정보(날짜, 일정 수) -> 액션(입력) -> 결과(목록) 순으로 레이아웃 흐름을 재설계.

## 3. Implementation Proposal (구현 제안)

### A. 레이아웃 순서 재배치 (Top-Down Flow)
1.  **Header (Magazine Style)**: 현재의 날짜 표시를 유지하되, 전체적인 시인성 확보를 위해 상단에 고정.
2.  **Summary/Mini-Stats**: 오늘 남은 일정 수 등을 작게 표시하여 대시보드 성격 강화.
3.  **Entry Form (입력창)**: 시계 아이콘 클릭 시에만 확장되는 것이 아니라, 상시 노출되되 미니멀하게 접혀있다가 포커스 시 부드럽게 확장되는 구조.
4.  **List Area (스크롤 영역)**: 하단에 넓게 배치하여 일정 목록을 한눈에 파악.

### B. 상시 오버레이 및 글래스모피즘 고도화
- **Floating Panel**: `SideBoard`를 화면 우측 끝에 붙이는 대신, 8~12px 정도의 여백을 둔 플로팅 카드로 변경.
- **Dynamic Blur**: 배경 캘린더가 비치는 투명도를 조절하고, 심리스(Seamless)한 보더 처리를 통해 고급스러운 입체감 부여.

### C. 인터렉션 고도화
- **Entry Mode Tab**: '일정'과 '할 일' 전환 시 탭의 언더라인 이동 애니메이션을 더욱 쫀득하게 처리.
- **Scroll Synchronization**: 목록 스크롤 시 상단 입력창이 자연스럽게 투명해지거나 작아지는 효과 검토.

## 4. Implementation Plan (수행 계획)

### Step 1: 구조적 레이아웃 변경 (SideBoard.jsx)
- [ ] 메인 컨테이너를 플로팅 스타일로 전환 (CSS 수정).
- [ ] 헤더 - 요약 - 입력폼 - 리스트 순으로 컴포넌트 배치 순서 조정.

### Step 2: 디자인 시스템 고도화 (SideBoard.css)
- [ ] 상시 오버레이를 위한 `box-shadow` 및 `margin` 보정.
- [ ] 각 섹션별 경계(Divider)를 선이 아닌 면(Space/Background)으로 구분하여 모던함 강조.

### Step 3: 디테일 및 애니메이션 폴리싱
- [ ] 입력창 포커스 시 주변 요소들의 투명도 조절 등 마이크로 애니메이션 추가.

## 5. Behavioral Summary (기대 효과)
재설계된 `SideBoard`는 사용자가 페이지에 진입했을 때 오늘 할 일을 직관적으로 파악(상단 헤더/요약)하고, 즉시 기록(입력 폼)하며, 전체 리스트를 편안하게 확인(하단 리스트)할 수 있는 최적화된 사용자 흐름을 제공합니다.
