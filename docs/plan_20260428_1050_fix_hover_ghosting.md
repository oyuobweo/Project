# Implementation Plan - Fixing Footer Hover Ghosting & Style Resync (v2.5)

## 1) Problem Summary
플러스(`+`) 아이콘 호버 시 시계 아이콘이 반응하는 간섭 현상(Ghosting)을 해결하고, 플러스 아이콘의 호버 효과를 시계 아이콘과 완벽히 동일한 방식(배경 하이라이트 + 보라색 + 확대)으로 재구현함. 

## 2) Design Summary
- **이벤트 격리**: 시계 아이콘과 플러스 아이콘의 호버 스타일을 그룹화하지 않고 개별 선택자로 명시하여 브라우저의 이벤트 타겟팅 오류 가능성 차단.
- **스타일 완전 동기화**: 
    - 배경 하이라이트: `rgba(255, 255, 255, 0.08)` 추가.
    - 컬러 전환: `var(--primary)`.
    - 확대 애니메이션: `scale(1.05)`.
- **레이아웃 안정화**: `32x32` 고정 크기를 유지하며 정렬 보정.

## 3) Implementation Plan

### Step 1: 호버 스타일 개별 정의 (간섭 방지)
- [ ] `SideBoard.css`에서 그룹화된 `.stealth-input-wrapper:hover, .submit-pill:hover`를 삭제.
- [ ] `.stealth-input-wrapper:hover` 전용 규칙 작성.
- [ ] `.submit-pill:hover` 전용 규칙 작성 (배경색 복구 포함).

### Step 2: 플러스 버튼 물리 속성 재확인
- [ ] `submit-pill`이 `button` 태그이므로 `outline: none`, `appearance: none` 등을 통해 기본 스타일 간섭 제거.
- [ ] `z-index`를 명시적으로 부여하여 클릭 영역 중첩 방지 (필요 시).

### Step 3: 라이트 테마 개별 정의
- [ ] 라이트 테마 호버 배경색(`0.04`)도 개별적으로 적용.

### Step 4: 최종 시각 검증
- [ ] 브라우저에서 플러스 아이콘에 마우스를 올렸을 때 **플러스 아이콘만** 반응하는지 확인.
- [ ] 시계 아이콘과 피드백의 형태가 100% 일치하는지 확인.

## 4) Behavioral Summary
푸터 하단의 두 아이콘이 각각 독립적인 히트 영역을 가지며, 마우스 오버 시 동일한 시각적 언어로 사용자에게 피드백을 제공합니다. 시계 버튼과 플러스 버튼이 서로 간섭하지 않고 깔끔하게 동작합니다.

## 5) Self Code Review
- **원인 분석**: 그룹화된 CSS 선택자 자체의 문제는 아니나, 레이아웃 상의 미세한 겹침이나 브라우저의 렌더링 최적화 과정에서 타겟팅 오차가 발생한 것으로 보임. 개별 정의와 영역 명시를 통해 이를 해결함.
