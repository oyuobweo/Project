# Implementation Plan - Re-synchronizing Footer Icon Hover Effects (v2.4)

## 1) Problem Summary
플러스(`+`) 아이콘의 호버 애니메이션을 시계 아이콘과 완벽히 동일한 스타일로 다시 통일함. 이전 단계에서 제거했던 배경 하이라이트(프레임) 효과를 복구하고 확대 비율을 조정하여, 푸터 영역의 모든 액션 버튼이 일관된 사용자 경험을 제공하도록 함.

## 2) Design Summary
- **동일 피드백**: 두 아이콘 모두 호버 시 동일한 보라색 하이라이트 배경과 컬러 전환 적용.
- **정밀 동기화**: 
    - 배경색: `rgba(255, 255, 255, 0.08)` (Dark) / `rgba(0, 0, 0, 0.04)` (Light).
    - 확대 애니메이션: `scale(1.05)`.
    - 전환 효과: `0.2s cubic-bezier(0.4, 0, 0.2, 1)`.

## 3) Implementation Plan

### Step 1: 호버 스타일 통합 재정의
- [ ] `SideBoard.css`에서 개별로 분리되어 있던 `.stealth-input-wrapper:hover`와 `.submit-pill:hover`를 다시 그룹화.
- [ ] 플러스 버튼에 `background: rgba(255, 255, 255, 0.08);`을 다시 적용.
- [ ] 플러스 버튼의 확대 비율을 `scale(1.15)`에서 `scale(1.05)`로 수정하여 시계 아이콘과 일치시킴.

### Step 2: 라이트 테마 스타일 통합
- [ ] `.theme-light` 환경의 호버 배경색(`0.04`)도 두 아이콘 모두에 적용되도록 그룹화.

### Step 3: 최종 검증
- [ ] 브라우저에서 시계 아이콘과 플러스 아이콘을 번갈아 호버하며 완전히 동일한 시각적 효과가 나타나는지 확인.

## 4) Behavioral Summary
푸터 하단의 두 아이콘 버튼이 다시 완벽한 쌍둥이 스타일로 돌아갑니다. 사용자는 어느 아이콘에 마우스를 올려도 동일한 배경 하이라이트와 부드러운 확대 반응을 경험하게 됩니다.

## 5) Self Code Review
- **결정**: 디자인 일관성이 최우선이므로, 이전의 미니멀 스타일 실험을 종료하고 가장 안정적이고 통일감 있는 시계 아이콘 스타일로 전체를 통합함.
- **결과**: 푸터 영역의 완성도가 다시 높아짐.
