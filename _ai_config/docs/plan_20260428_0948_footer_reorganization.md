# Implementation Plan - Minimal Footer Actions Reorganization (v1.8)

## 1) Problem Summary
입력 폼 하단의 '등록' 버튼에서 텍스트를 제거하고 플러스(`+`) 아이콘만 남긴 뒤, 이를 시계 아이콘 바로 옆으로 이동 배치함. 이를 통해 푸터 레이아웃을 더욱 미니멀하게 개선하고 주요 액션들을 한곳에 집중시킴.

## 2) Design Summary
- **아이콘 전용 버튼**: '등록' 버튼을 시계 아이콘과 동일한 규격(`32x32`)의 아이콘 버튼으로 변경.
- **위치 재배치**: 좌측 `entry-footer-actions` 영역으로 이동하여 시계 아이콘과 나란히 배치.
- **시각적 일관성**: 두 아이콘 버튼이 동일한 크기, 호버 효과, 간격을 공유하도록 설정.

## 3) Implementation Plan

### Step 1: SideBoard.jsx 구조 변경
- [ ] `submit-pill` 버튼 내의 `<span>등록</span>` 제거.
- [ ] 버튼 엘리먼트를 `entry-footer-right`에서 `entry-footer-actions` 내부로 이동.

### Step 2: SideBoard.css 스타일 조정
- [ ] `.submit-pill`을 아이콘 버튼 규격에 맞게 수정.
    - `width: 32px;` 추가.
    - `padding: 0;`으로 변경하여 정사각형 형태 확보.
    - 기존 텍스트 정렬용 `margin` 제거.
- [ ] 시계 아이콘과 플러스 아이콘 사이의 간격(`gap: 8px`) 확인.

### Step 3: 최종 검증
- [ ] 브라우저에서 시계와 플러스 아이콘이 나란히 정렬되어 있는지 확인.
- [ ] 호버 시 두 버튼의 크기와 배경색 변화가 일치하는지 확인.
- [ ] 텍스트가 사라진 뒤에도 버튼의 기능(Submit)이 정상 작동하는지 확인.

## 4) Behavioral Summary
우측 하단에 있던 '등록' 버튼이 사라지고, 좌측 하단에 시계와 플러스 아이콘이 나란히 위치하게 됩니다. 훨씬 더 간결하고 모던한 입력 폼 디자인이 완성됩니다.

## 5) Self Code Review
- **핵심**: 텍스트가 사라지므로 아이콘만으로도 '등록' 기능임을 인지할 수 있도록 시각적 피드백(호버 시 컬러 변화 등)을 명확히 유지함.
- **결과**: 푸터 영역의 여백이 넓어져 전체적인 가독성이 향상됨.
