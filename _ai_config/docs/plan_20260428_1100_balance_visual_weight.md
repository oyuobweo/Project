# Implementation Plan - Balancing Visual Weight of Footer Icons (v2.7)

## 1) Problem Summary
시계 아이콘에 비해 플러스(`+`) 아이콘의 확대 효과가 덜 눈에 띄는 현상을 구조적/시각적 분석을 통해 해결함. `button` 태그의 렌더링 특성을 보정하고, 선이 얇은 플러스 아이콘의 시각적 무게감을 보완하기 위해 확대 비율과 선 두께(`stroke-width`)를 추가로 상향 조정함.

## 2) Design Summary
- **구조적 분석**: 시계는 `div`, 플러스는 `button` 태그를 사용 중임. 브라우저의 기본 버튼 스타일이 애니메이션을 억제할 수 있으므로 명시적 리셋 강화.
- **시각적 무게감 보정**:
    - **두께 강화**: 호버 시 플러스 아이콘의 선 두께를 살짝 두껍게 하여 인지력 상승.
    - **비율 상향**: 기하학적으로 부피가 작은 플러스 아이콘의 확대 비율을 시계보다 더 크게(`1.25`) 설정하여 체감상 동일한 크기 변화 유도.

## 3) Implementation Plan

### Step 1: 플러스 버튼 구조적 리셋 강화
- [ ] `.submit-pill`에 `padding: 0; overflow: visible;` 등을 추가하여 내부 SVG의 움직임 공간 확보.

### Step 2: 플러스 아이콘 전용 호버 효과 강화
- [ ] `.submit-pill:hover svg`의 `transform: scale`을 `1.25`로 상향.
- [ ] `stroke-width`를 조절할 수 있다면 추가 시도 (Lucide 아이콘 속성).

### Step 3: 시계 아이콘과 체감 대비 확인
- [ ] 두 아이콘을 번갈아 호버하며 '튀어나오는 정도'가 시각적으로 대등한지 확인.

## 4) Behavioral Summary
구조적인 차이와 아이콘 형태의 차이를 보정하여, 사용자가 어느 버튼을 보더라도 동일하게 역동적이고 명확한 피드백을 느끼게 됩니다. 플러스 아이콘은 이제 시계 아이콘만큼이나 존재감 있게 확대됩니다.

## 5) Self Code Review
- **원인**: 시계는 원형(Circle) 베이스라 면적이 넓어 확대가 잘 보이지만, 플러스는 얇은 선(Cross) 형태라 같은 비율로 키워도 면적 변화가 작음. 이를 '비율 상향'으로 해결하는 것이 정석임.
